## 反复复核中的补充处理

- 自定义 processing 登记与队列键空间的冲突、删除和清空路径，以及无历史记录的消息清理，增加边界校验和原子保护。旧历史的归档与清理也识别自定义 processing。
- 外存适配器旧签名在调用前识别，避免内部 `TypeError` 导致重复上传；历史错误信息不含外存异常原文。
- 外存 TTL 清理原先遇到损坏元数据会退回 TTL 删除，且可与延长保留期交错；隔离复现后使用共享 SQLite 锁与原子元数据替换，无法读取时保守跳过。正常过期、锁跨进程、失败回滚与 Redis GC 都有回归。
- 本机无 token 外存服务原先允许跨来源 multipart 上传；加入写请求同源校验，并保留服务端 SDK 无 Origin 访问。
- 修正高级示例的停止重试、UTC 时间桶、执行路径和有界去重描述。新闻发现结果将待投递数标为 `planned_emissions`，避免把去重拒绝的条目描述为已投递。
- 按上述补充更新计划与设计。最后一轮对令牌、键空间、归档、外存、鉴权和例子的复核未再发现未解决的严重错误；此结论限于审查和测试范围，不构成不存在其他缺陷的保证。
