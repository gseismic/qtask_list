# 计划：管理后台界面美化与字号优化

- 创建时间：2026-10-17 18:26（Asia/Shanghai）
- 实际模型：GLM-5.3-Flash（account:bigmodel-individual-coding-plan/GLM-5.3-Flash）
- 分析范围：WORKTREE，基准提交 `ae4cf1dbc3d6027de2244407dcd1dff2800df0e9`；相关未提交内容以任务完成时的前端源码为准
- 用户诉求：管理后台界面不美观、字体太小，要求优化显示（附总览页截图）

## 现状认知卡（存量勘察）

信息架构保持不变：左侧导航（总览/队列/任务/Worker/告警/教程）+ 顶栏（连接状态/刷新/主题）+ 内容区 6 个页面。

现有 tokens（`qtask_list/frontend/src/styles.css`）：

- 字号：正文 13px，徽章/表头/辅助文字 12px，页标题与卡片标题 18px，KPI 值 24px；无字阶变量，数值散落各类。
- 色彩：GitHub 风浅色（primary `#0969da`），深色主题成对维护；语义色 dim 背景已有。
- 形状与层次：圆角 4/6/8px 混用；卡片无投影、边框 `#d0d7de` 偏重生硬；阴影仅两档且只用于弹层。
- 密度：KPI/表格/矩阵行 padding 偏小（8–10px），topbar 52px，侧栏 200px。

痛点结论：整体观感"平淡、拥挤、字小"，主因为①字阶整体低一档、②缺圆角/阴影/过渡的层次体系、③控件密度过高。信息架构与类名结构无需改动。

## 目标与范围

- 目标：在不改动页面信息架构、DOM 结构与交互行为的前提下，整体提升美观度并把字号上调一档，浅色/深色主题同步。
- 范围：`qtask_list/frontend/src/styles.css`（重写 tokens 与组件样式，保留全部既有选择器与响应式断点行为）；`qtask_list/dashboard/static/css/login.css`（对齐新观感：字号、圆角、投影）。
- 不在本次处理：页面布局重构、新功能、后端 `dashboard/main.py`、SPA 构建产物手工编辑（产物由 `pnpm build` 重新生成）。

## 设计 tokens（新版）

字阶 5 档（变量化，清除魔法数）：

| token | 值 | 用途 |
| --- | --- | --- |
| `--fs-xs` | 12.5px | 徽章、表头、辅助说明、时间 |
| `--fs-md` | 14px | 正文、表格、按钮、输入框、导航 |
| `--fs-lg` | 16px | 区块标题、tab |
| `--fs-xl` | 20px | 页面标题、卡片标题 |
| `--fs-2xl` | 28px | KPI 数值 |

其他 tokens：

- 圆角 3 档：`--r-sm: 6px`（徽章、代码块）、`--r-md: 8px`（按钮、输入、分段控件）、`--r-lg: 12px`（卡片、弹窗、抽屉）。
- 阴影 2 档：`--shadow-1` 卡片浅投影；`--shadow-2` 弹层深投影。
- 色彩（保持蓝/绿/黄/红语义，更新为更现代的值；正文对比度 ≥ 4.5:1）：浅色 primary `#2563eb`、success `#16a34a`、warning `#b45309`、danger `#dc2626`，边框淡化至 `#dde3ea`，正文 `#1a2433`；深色成对更新（primary `#6ea8fe`、success `#4ade80`、warning `#fbbf24`、danger `#f87171` 等）。
- 统一过渡 `--trans: 140ms ease`，用于按钮/卡片/输入的 border、背景、投影、位移。

组件级调整（全部通过既有类名实现）：正文字号 14px/行高 1.6；导航项与顶栏加大点击区；卡片 12px 圆角加浅投影；KPI 卡 padding 18–20px、数值 28px、可点击卡 hover 上浮；表格单元格 padding 10–12px；按钮 padding 7px 14px、primary 加投影；徽章改胶囊形；输入框 focus 环 3px；细化滚动条与全局 focus-visible。

## 实施步骤

1. 重写 `styles.css`：先 tokens（浅色/深色两套），再逐段升级既有选择器；保留全部类名、媒体查询断点（1100/1200/900/700px）及其行为。

- 浏览器实测：总览页、队列/任务页、登录页在浅色与深色主题下无破版、无文字截断异常，字号明显提升；截图存入 `docs/test/20261017-18-WORKTREE/`。
- 完成标准：上述验证通过且界面达到"字号舒适、层次分明"的改版目标；后端测试不受影响（本次不改 Python 代码）。

## 主要风险与回滚

- 风险：全局字号上调可能造成个别表格/矩阵在窄屏换行或拥挤 → 保留既有横向滚动与响应式断点，浏览器窄屏抽查。
- 风险：深色主题遗漏同步 → tokens 集中定义，浅/深成对修改并逐主题截图检查。
- 回滚：改动集中在 2 个 CSS 文件与构建产物，`git checkout -- ` 相关文件即可整体回滚；不触碰用户已有未提交改动（AGENTS.md 的本地修改保留）。
