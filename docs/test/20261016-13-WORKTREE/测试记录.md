## 测试过程中的失败、限制与清理

- 浏览器脚本第一次尝试因 Playwright CLI 执行环境未提供全局 URL 构造器而失败，见[首次尝试](./task-search-browser-attempt1.txt)。已改为使用页面 origin 和字符串解析；修改后首轮及最终轮均通过。该失败来自测试脚本，没有计为产品通过。
- 缓存校验首轮通过后，自查发现批量失效时可能重复扫描键空间，改为所有缺失候选共用一次 processing 扫描。新增测试验证正常缓存命中不扫描、多个失效候选只扫描一次，且不会提前发现新的未注册队列；最终全量和浏览器均重新验证。
- 没有执行生产环境负载测试、多浏览器兼容测试或真实业务 handler。新出现的未注册 V1 队列仍沿用既有每小时发现窗口；已缓存队列的失效在下次查询核实。注册表中的空队列仍有意保留。
- 两轮私有 Redis 均核验数据为空后关闭；测试浏览器和临时 Dashboard 已停止，socket 目录已清理。测试服务收到 SIGINT 后的退出码 130/KeyboardInterrupt 为主动关闭记录，见[服务日志](./browser-server-final.txt)。未清理或重启原有 localhost:6379 Redis、8766 Dashboard。
- 代码及 SPA 产物已经更新，现有 8766 Dashboard 仍运行修复前加载的 Python 代码；使用该进程需重启加载修复。本次未提交、未推送。
