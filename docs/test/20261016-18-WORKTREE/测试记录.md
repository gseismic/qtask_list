## 重点回归

- monkeypatch Redis 的 scan 和 scan_iter 为直接失败，验证 queue_names、list_queues、list_workers 仍能工作；未注册 List、历史、processing、心跳和 Worker 注册表均不能绕过队列注册表加入全局列表。
- 同一个 QueueAdmin 立即观察注册项增加、删除、后续真实 enqueue 及外部清空；注册表中的空队列保持可见。
- 空闲 Worker 无需先投递任务就登记队列；TTL 心跳、Worker 和队列登记同时生效；外部清空后下一次心跳可重新登记。
- Worker 退出时保留残留 processing 的注册项，能按失联 Worker 诊断和恢复；恢复后清理 Worker 注册项，逻辑队列仍保留。
- 三类 Redis 键类型冲突不会留下部分登记；两个线程并发登记重叠队列名，只有一方成功，另一方无残留键。
- 在“读取心跳为空”和“清理注册项”之间注入真实续租，原子复核保护新注册项。
